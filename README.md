# CyberShield — Cyber Safety and Digital Fraud Awareness

CyberShield is an educational community-project website that helps students, older adults, and general internet users recognize common digital scams and practise safer responses. It is an existing single-page Vite application built with HTML, CSS, vanilla JavaScript, and Three.js.

## Problem and objectives

Unexpected messages, payment requests, impersonation, and pressure tactics can make it difficult for people to verify an online request. CyberShield teaches users to pause, check through a trusted channel, protect credentials, and use official reporting resources. It is an awareness resource—not a bank, emergency service, complaint-filing system, or certified training provider.

## Features

- Eight concise bilingual lessons: phishing, UPI/QR, fake support, job/scholarship fraud, OTP/PIN/remote access, impersonation, investment fraud, and AI/synthetic deception. Each lesson includes warning signs, a fictional example, a safer response, a checklist, and an after-action note.
- A scroll-responsive gallery linking to the eight lessons.
- An interactive Scam Lab with eight fictional scenarios, two decision stages per scenario, feedback, consequences, prevention checklists, per-scenario replay, score, progress, and full replay.
- English and Kannada interface and learning content. Kannada is not represented as professionally reviewed.
- Four-step safety guidance and outbound links to the Government of India National Cyber Crime Reporting Portal and financial cyber-fraud helpline 1930. The official I4C FAQ says financial-fraud complaints made by phone must later be completed on the portal; confirm current instructions on official channels.
- A Three.js shield with a CSS illustration fallback, reduced-motion handling, visibility-aware rendering, and capped device pixel ratio.
- No backend, payment flow, user account, complaint submission, or collection of OTPs, PINs, passwords, or financial information.

## Technology and architecture

- HTML page structure: `index.html`
- Vanilla JavaScript modules: `src/main.js`, `src/scam-lab.js`, `src/translations.js`, `src/scene.js`
- CSS: `src/styles.css` and `src/editorial.css`

## Requirements and local setup

Install a Node.js release supported by the locked Vite 7 version, then run in the project directory:

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173/`). Stop the server with Ctrl+C.

Available scripts:

| Command | Purpose |
|---|---|
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create the production bundle in `dist/` |
| `npm run preview` | Serve the built `dist/` locally |

No separate automated test or lint script is configured. The manual/browser verification record is in [testing report](docs/testing-report.md).

## Deployment

Build with `npm run build` and serve `dist/` using a static host that supports HTTPS. The page uses hash anchors, so it does not require client-side route rewrites. Configure HTTPS and any security headers (for example, an appropriate Content-Security-Policy) at the hosting platform; this static frontend does not itself enforce response headers. No deployment has been performed.

## Privacy, security, and limitations

- There is no backend or form submission. The only persisted preference is the language key `cybershield-language` in this browser’s local storage; quiz progress is not persisted.
- The Scam Lab is an isolated educational simulation with fictional content and no live links or transactions.
- The project does not contact law enforcement, banks, or a helpline; reporting links leave the site.
- Google Fonts are requested from Google when network access is available. The local image files do not require hotlinked image requests.
- The Three.js production chunk exceeds Vite’s 500 kB advisory threshold; see the testing report.
- Official reporting instructions and contact availability may change. Check the Government of India portal and your bank/payment provider’s official contact details.
- This project does not provide investment advice, professional cybersecurity training, or official certification.
