# CyberShield User Manual

## Open the project

For a locally hosted copy, ask the project maintainer to start the site with `npm run dev`, then open the local address printed by Vite. A deployed copy should use its published HTTPS address. CyberShield does not require an account.

## Find your way around

Use the main navigation to open Home, Learn, Scam Lab, Safety Guide, Community, or Report. On a smaller screen, select the menu button to open the navigation; select it again or press Escape to close it. The Report menu links to the on-page resources, the official portal, and the helpline.

Use the “Skip to content” link at the top of the page to move past navigation. Keyboard users can move through links and buttons with Tab/Shift+Tab and activate them with Enter or Space.

## Change language

Choose **EN** for English or **ಕನ್ನಡ** for Kannada from the language selector. The selected language is remembered in this browser when storage is available. If storage is blocked, the current language still works for the visit.

## Learn about a scam topic

Open **Learn** or choose a card in the topic gallery. Each topic includes warning signs, a message clearly presented as fictional, a safer response, and an expandable checklist. If an event may already have occurred, follow the “If you already acted” guidance and contact the relevant provider through its official channel.

## Use the Scam Lab

The Scam Lab is a fictional learning simulation; it does not send messages or perform payments.

1. Read the labelled fictional message.
2. Choose the answer that best identifies a warning sign.
3. Read the explanation and the outcome for the choice.
4. Choose a safe response and review the prevention checklist.
5. Replay that scenario if useful, continue to another scenario, or finish to see the score.
6. Use **Run simulation again** to restart the complete set.

Never enter an OTP, PIN, password, card information, or other private information. No such input is needed.

## Use the Safety Guide and reporting links

The guide’s four steps are: stop contact, verify independently, secure and document, and report promptly. For Indian cybercrime reporting, the site links to the National Cyber Crime Reporting Portal at <https://cybercrime.gov.in/>. The I4C FAQ states that financial cyber-fraud complaints can be reported by calling 1930 and must later be completed on the portal with additional information. Also contact your bank/payment provider through its official channel. Reporting instructions and contact availability can change; confirm the latest process on official sources. CyberShield does not submit a complaint or contact these organizations for you.

Keep relevant transaction references, screenshots, messages, suspicious contact details, and dates/times for an official report. Do not send sensitive records to CyberShield.

## Privacy and limitations

The site has no user account, backend, or form submission. It stores only the language preference in browser local storage. Quiz score is temporary and is not saved. Optional sound is off by default and is generated locally by the browser after the user enables it. The 3D shield may be replaced by a CSS illustration if WebGL is unavailable.
